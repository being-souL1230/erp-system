# 🏫 Student ERP System (Flask + MySQL)

A complete **Student ERP system** built using **Flask**, **MySQL**, and **HTML/CSS/JavaScript**. This system allows students and faculty to log in, track attendance, manage assignments, and more — all through an intuitive dashboard.

---

## 🚀 Features

### 👨‍🎓 Student Panel:
- Secure login system with email & password
- Dashboard with glassmorphism UI
- View attendance records (percentage + monthly breakdown)
- View submitted assignments

### 👨‍🏫 Faculty Panel:
- Faculty login with email & password
- Dashboard to upload/update student attendance
- Add and track assignments
- Full control over student records

## 🛠️ Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/being-souL1230/erp-system.git
cd erp-system
```

### 2. Create Virtual Environment
python -m venv venv
venv\Scripts\activate   # (Windows)

### 3. Install requirements 

pip install -r requirements.txt

### 4. Run the app

python app.py
